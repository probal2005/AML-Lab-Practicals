## 4. THEORY

Federated Learning is a distributed machine learning approach in which multiple clients collaboratively contribute to a learning task without requiring their local training data to be collected into one central training dataset.

In a typical Federated Learning environment:

1. A central coordinator defines the learning task.
2. The dataset is distributed or maintained across multiple clients.
3. Each client trains a model using its own local data.
4. Clients share selected model information or updates instead of directly transferring their raw local training records.
5. A central aggregation process combines the contributions.
6. The resulting model or prediction can be evaluated and used for the intended application.

For example, multiple hospitals can train machine learning models using their own patient records. This approach can reduce the need to transfer sensitive training records between institutions.

### Working Principle in This Experiment

This practical demonstrates a simplified Federated Learning workflow:

- The Breast Cancer Wisconsin dataset is divided into training and testing sets.
- The training data is divided into four client partitions.
- Each client independently trains a Logistic Regression model.
- Every client generates predictions for the same test dataset.
- The predictions are combined using majority voting.
- The combined predictions are evaluated and compared with individual client predictions.

**Important implementation note:** This experiment performs prediction-level aggregation using majority voting. It is a simplified Federated Learning simulation, not a complete federated optimization protocol such as Federated Averaging (FedAvg), which aggregates model parameters or updates.

The experiment also exports the source dataset as a CSV output file for inspection. Therefore, its data-locality workflow is educational and should not be considered a production privacy guarantee.

## 7. IMPLEMENTATION

### Step 1: Import Required Libraries

The experiment uses NumPy, Pandas, Matplotlib, and Scikit-learn for data processing, machine learning, evaluation, and visualization.

### Step 2: Load the Dataset

The Breast Cancer Wisconsin dataset is loaded using Scikit-learn's `load_breast_cancer()` function.

The dataset contains 569 samples, 30 numerical input features, and two target classes.

### Step 3: Split the Dataset

The dataset is divided into training and testing sets using `train_test_split()`.

- Training data: 80%
- Testing data: 20%
- Random state: 42
- Stratification: Enabled

### Step 4: Perform Feature Scaling

`StandardScaler` is used to standardize the input features.

The scaler is fitted only on the training data and then applied to both training and testing data to avoid data leakage.

### Step 5: Divide Training Data into Clients

The training dataset is divided into four client partitions using NumPy's `array_split()`.

Each client receives its own local training features and corresponding labels.

### Step 6: Train Local Models

Each client independently trains a Logistic Regression model using:

`LogisticRegression(max_iter=1000, random_state=42)`

Every trained client model generates predictions for the same test dataset.

### Step 7: Evaluate Client Models

The accuracy and classification report of each client model are calculated using Scikit-learn evaluation functions.

### Step 8: Perform Majority Voting

The predictions from all four clients are collected into a prediction matrix.

For each test sample, the predicted class receiving the highest number of votes is selected as the final combined prediction.

### Step 9: Evaluate Combined Predictions

The combined predictions are evaluated using:

- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix
- Classification Report

### Step 10: Save Results

The program saves the experiment summary, client predictions, accuracy comparison, classification reports, confusion matrix, dataset CSV, and graphical visualizations inside the `output/` directory.
