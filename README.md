# Advance Machine Learning Lab Practicals

A collection of **15 Advance Machine Learning (AML) laboratory practicals** implemented with Python. This repository contains practical implementations, experiment-specific documentation, source code, datasets or input samples, generated results, visualizations, and execution records.

The work covers core machine learning methods as well as deep learning, probabilistic modelling, federated learning, computer vision, generative models, and explainable AI.

## Topics and Skills Covered

- **Supervised Learning:** Linear Regression, Ridge and Lasso regularization, SVM classification, and ensemble methods.
- **Unsupervised Learning:** AGNES, DIANA, and Self-Organizing Maps (SOM).
- **Probabilistic Modelling:** Gibbs Sampling, Markov Chain Monte Carlo (MCMC) concepts, and Hidden Markov Models (HMM).
- **Deep Learning:** Deep Belief Networks (DBN) and Generative Adversarial Networks (GAN).
- **Distributed Learning:** Federated Learning workflows and client-based model training.
- **Computer Vision:** Image segmentation using OpenCV and object detection using YOLO.
- **Explainable AI (XAI):** Model interpretation using SHAP and LIME.
- **Practical Evaluation:** Evaluation metrics, comparison tables, generated plots, CSV files, and execution logs where provided by an experiment.

## Datasets and Inputs

The practicals use datasets and input files appropriate to each task. Examples documented in the experiment READMEs include:

- Scikit-learn Diabetes, Iris, Digits, and Breast Cancer Wisconsin datasets.
- Synthetic bivariate normal distribution for Gibbs Sampling.
- Weather observation sequences for the HMM practical.
- MNIST handwritten digit dataset for the GAN practical.
- Image inputs and traffic video samples for computer vision practicals.

Dataset sources, input-file details, and preprocessing steps are documented in the relevant experiment README. Check those instructions before running an experiment.

## How to Use This Repository

1. Open the practical folder you want to study.
2. Read its `README.md` first.
3. Review the Python source code and documented theory.
4. Install the dependencies specified for that practical.
5. Follow the execution commands provided in that practical.
6. Inspect the generated outputs, plots, CSV files, and execution logs.

> **Important:** Dependencies and execution steps can differ between practicals. There is no single root-level environment or universal run command documented for all 15 experiments. Always follow the instructions inside the selected experiment folder.

## Results and Documentation

- Model evaluation reports and comparison tables.
