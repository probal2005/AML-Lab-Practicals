# 3. THEORY

## 3.1 Introduction to Hidden Markov Models

A Hidden Markov Model is a statistical model used to represent sequential data in which the actual states of a system cannot be observed directly. Instead, the hidden states generate observable outputs.

An HMM follows the Markov property, which states that the current hidden state depends only on the previous hidden state.

HMMs are commonly used in speech recognition, natural language processing, weather modelling, biological sequence analysis, and activity recognition.

## 3.2 Components of an HMM

An HMM is represented by three main parameters:

λ = (A, B, π)

Where:

- A: State transition probability matrix.
- B: Observation emission probability matrix.
- π: Initial-state probability distribution.

### A. Hidden States

Hidden states are the actual conditions of the system that cannot be observed directly.

In this experiment, the hidden states are:

- Rainy
- Sunny

### B. Observations

Observations are the visible outputs generated by the hidden states.

In this experiment, the observations are:

- Walk
- Shop
- Clean

### C. Initial-State Probabilities

Initial-state probabilities represent the probability of starting in each hidden state.

The initial probability vector is:

π = [0.6, 0.4]

Therefore:

- Probability of starting in Rainy = 0.6
- Probability of starting in Sunny = 0.4

### D. State Transition Probability Matrix

The transition matrix represents the probability of moving from one hidden state to another.

| Current State | Rainy | Sunny |
| ------------- | ----- | ----- |
| Rainy         | 0.7   | 0.3   |
| Sunny         | 0.4   | 0.6   |

Each row sums to 1 because it represents all possible next states from the current state.

### E. Observation Emission Probability Matrix

The emission matrix represents the probability of observing a particular activity given a hidden weather state.

| Hidden State | Walk | Shop | Clean |
| ------------ | ---- | ---- | ----- |
| Rainy        | 0.1  | 0.4  | 0.5   |
| Sunny        | 0.6  | 0.3  | 0.1   |

For example, the probability of observing Walk when the hidden state is Sunny is 0.6.

## 3.3 Viterbi Algorithm

The Viterbi algorithm is a dynamic programming algorithm used to find the most likely sequence of hidden states corresponding to a given sequence of observations.

It evaluates possible state sequences using the initial-state, transition, and emission probabilities and identifies the path with the highest probability.

The most likely hidden-state sequence is represented as:

Q\* = argmax P(Q | O, λ)

Where:

- Q\* represents the most likely hidden-state sequence.
- O represents the observed sequence.
- λ represents the HMM parameters.

## 3.4 Posterior Probabilities

Posterior probabilities estimate the probability of each hidden state at a particular time step, given the complete observation sequence.

They help us understand how likely each hidden state is at each position in the sequence.

## 3.5 Log Probability

The log probability measures how likely the observed sequence is under the configured HMM. Log probabilities are useful when dealing with very small probability values because they help avoid numerical underflow.

## 3.6 Applications of HMM

Hidden Markov Models are used in:

1. Speech recognition.
2. Weather and time-series modelling.
3. Human activity recognition.
4. Biological sequence analysis.
5. Natural language processing.
6. Sequential pattern recognition.
